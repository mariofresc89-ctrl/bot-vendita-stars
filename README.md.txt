# Bot Vendita Telegram Stars

Bot Telegram che vende contenuti digitali utilizzando Telegram Stars.

## Come funziona
1. L'utente avvia il bot con /start
2. Clicca "Acquista" e paga in Stars
3. Il bot consegna il contenuto digitale

## Setup
1. Clona il repository
2. Installa le dipendenze: `pip install -r requirements.txt`
3. Inserisci il token di @BotFather in `bot_vendita.py`
4. Esegui: `python bot_vendita.py`
